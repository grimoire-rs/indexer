What this package is, how to run it, and how it is released: `README.md`.
This file exists for one reason — to make the rule catalog discoverable.

Path-scoped rules under `.claude/rules/` fire only once a matching file is
already open, which is never true during planning or research. Scan the
catalog before designing anything that touches the renderer's CSS.
